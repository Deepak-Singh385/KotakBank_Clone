**Kotak Bank Website Clone**

A front-end banking dashboard inspired by Kotak Mahindra Bank, built with HTML, CSS, and vanilla JavaScript. This project is for learning and portfolio demonstration only; it is not an official Kotak Mahindra Bank application.

**Website Link** : https://kotakbank-git-main-deepak-singh385s-projects.vercel.app

**Features:**
Login with predefined demo accounts
Dashboard displaying account balance and transaction movements
Deposit and withdrawal summaries
Transfer money between demo accounts
Request a simulated loan
Close a demo account
Sort transaction movements
Logout timer
Informational sections for privacy policy, terms, and contact details
All account information and transactions are stored in the JavaScript code and run in the browser. There is no real banking connection or backend database.

**Built With:**
HTML5 — page structure
CSS3 — styling and layout
JavaScript (ES6+) — login interactions, account calculations, and simulated banking operations
Google Fonts — Poppins typeface
Vercel — deployment and hosting
